# Спидпеинт

Статическая мастерская для рисования по фотографии. JPG, PNG и WEBP декодируются в браузере. Фото остаётся на устройстве.

1. Выберите фото или перетащите его на холст.
2. Настройте кисть и детализацию перед стартом. Темп можно менять во время просмотра.
3. Экспорт заново проигрывает все этапы с выбранной скоростью и записывает холст через MediaRecorder. Держите вкладку открытой до скачивания. Видео сохраняется в WebM или MP4 в зависимости от поддержки браузера.

Алгоритм переносит идеи из локальных Python-прототипов: лёгкий набросок и чистовой контур, заливка связных цветовых областей и отделка по касательным к градиенту. Для ранних мазков используется копия с длинной стороной до 960 пикселей. Чистовая кисть постепенно уточняет отличающиеся пиксели в исходном разрешении короткими локальными проходами. «Сохранить PNG» копирует исходный PNG или сохраняет декодированные пиксели JPG и WEBP без потерь при кодировании. Видео в исходном разрешении сжимает браузерный кодек.

Для локального запуска выполните `python -m http.server 8000` из папки проекта и откройте `http://localhost:8000/`. Для GitHub Pages используется корень ветки `main`.
