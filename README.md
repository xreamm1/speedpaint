# Спидпеинт

Статическая мастерская для рисования по фотографии. JPG, PNG и WEBP декодируются в браузере. Фото остаётся на устройстве.

1. Выберите фото или перетащите его на холст.
2. Настройте кисть и детализацию перед стартом. Щёлкните по главному объекту, если хотите начать набросок с него. Темп можно менять во время просмотра.
3. Экспорт заново проигрывает все этапы с выбранной скоростью и записывает холст через MediaRecorder. Держите вкладку открытой до скачивания. Видео сохраняется в WebM или MP4 в зависимости от поддержки браузера.

После лёгкого наброска кисть доводит основные тёмные контуры, затем намечает большие цветовые массы. Соседние области группируются по расположению и цвету. Внутри группы кисть добавляет тени и полутона, затем возвращается к контрастным краям, бликам и мелкой фактуре в несколько проходов. В основном режиме последний кадр и PNG содержат рисунок с холста. Настройка «Проявить оригинал» добавляет короткий проход точного уточнения. В этом режиме кнопка «Оригинал в PNG» сохраняет исходное изображение в PNG с исходными размерами. Записанное видео сжимается браузером. Максимальная длина стороны составляет 1280 пикселей или 720 на устройствах с сенсорным вводом. Формат и фактические размеры указаны на кнопках скачивания.

Экспериментальная настройка «Рисование по формам» включает геометрическую прорисовку белых лент на бирюзовых участках в режиме иллюстрации.

Для локального запуска выполните `python -m http.server 8000` из папки проекта и откройте `http://localhost:8000/`. Для GitHub Pages используется корень ветки `main`.

Исходники примеров — [Red Apple](https://commons.wikimedia.org/wiki/File:Red_Apple.jpg) Абхиджита Тембхекара ([CC BY 2.0](https://creativecommons.org/licenses/by/2.0/)), [натюрморт из примеров OpenCV](https://github.com/opencv/opencv/blob/master/samples/data/fruits.jpg) и иллюстрация EdiTool. Переход при прокрутке галереи перенесён из [EdiTool](https://editool.ru/).
